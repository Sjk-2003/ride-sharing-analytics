                Who does what for the business

                • Producer: stands in for the SwiftRide app, sending every ride request as it happens (2 per second).
                • Kafka: the company's event backbone. It stores every ride for 72 hours, so many teams can read the same data.
                • Kubernetes on EC2: keeps each service running and restarts it if it crashes.
                • Live website: the control room for today's decisions (drivers, surge, rewards).
                • Databricks: cleans and stores the history (Delta tables) and computes the official Gold reports.
                • S3: a cheap, durable data lake for finance reports, audits and future machine learning.
